В проекте реализованы автотесты для класса BooksCollector, который управляет коллекцией книг, их жанрами и списком избранного.

## Реализованные тесты

### add_new_book
Проверки метода добавления новых книг:
- добавление одной и нескольких книг
- невозможность добавления дубликатов
- невозможность добавления книги с названием длинне 40 символов 

---

### set_book_genre
Проверки установки жанра книге:
- установка жанра для существующей книги
- невозможность установки жанра, если он не входит в список допустимых

---

### get_book_genre
- коректное получение жанра книги по ее названию
- возврат пустой строки для книги, у которой жанр еще не установлен

---

### get_books_with_specific_genre
- получение списка книг по заданному жанру
- проверка корректности возвращаемого списка для разных жанров (использовала параметризацию)

---

### get_books_for_children
- возвращаются только книги с жанрами, разрешёнными для детей
- книги с возрастными ограничениями не попадают в результат

---

### Избранные книги:
Отдельными тестами проверены методы:
- добавление книги в избранное
- удаление книги из избранного
- получение списка избранных книг

### Используемые фикстуры:
В проекте используются фикстуры pytest для упрощения тестов:
- `collector` — пустой экземпляр `BooksCollector`
- `book` — экземпляр с добавленными книгами без жанров
- `genres` — экземпляр с книгами и установленными жанрами
